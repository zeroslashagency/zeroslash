## PRODUCTION WORKFLOW

### Pre-Production (Day 1-2)
**Research:**
- Identify target brand/topic
- Collect examples, data, screenshots
- Create redesign mockups (if applicable)

**Script:**
- Write full script (2,000-3,000 words)
- Include timestamps
- Plan visual assets

**Assets:**
- Screen recordings
- Design mockups
- Data visualizations
- B-roll footage

### Production (Day 3)
**Recording Setup:**
- Camera: iPhone/DSLR (1080p minimum)
- Mic: Lavalier or USB mic (clear audio essential)
- Lighting: Natural light + ring light
- Background: Clean office or branded backdrop

**Recording Tips:**
- Record intro 3 times (pick best energy)
- Use teleprompter for script
- Record screen separately (4K if possible)
- Get multiple takes of key points

### Post-Production (Day 4-5)
**Editing:**
- Cut filler words, long pauses
- Add b-roll every 3-5 seconds
- Include text overlays for key points
- Add chapters/timestamps
- Background music (low volume)
- Color correction

**Graphics:**
- Lower thirds with name/company
- Animated transitions
- Charts/graphs for data
- Before/after comparisons
- End screen with 2 video suggestions

### Publishing (Day 6)
**Upload Checklist:**
- Title (under 60 characters, keyword-rich)
- Description (first 150 characters critical)
- Tags (10-15 relevant tags)
- Thumbnail (1280x720px)
- End screens
- Cards (2-3 per video)
- Chapters/timestamps
- Subtitles (auto-generate + edit)

## THUMBNAIL STRATEGY

### Elements:
1. **High Contrast:** Bright colors, bold text
2. **Faces:** Emotional expressions (shocked, serious, thoughtful)
3. **Text:** 3-5 words max, large font (60-80pt)
4. **Branding:** Logo or color in corner
5. **Before/After:** Split screen for redesigns

### Colors:
- Primary: #FF0000 (red) for mistakes, problems
- Secondary: #00FF00 (green) for solutions, improvements
- Accent: #FFD700 (gold) for premium content

### Text Style:
- Font: Bold, sans-serif (Impact, Bebas Neue)
- Stroke: White or black outline for readability
- Shadow: Slight drop shadow

### Tools:
- Canva (templates)
- Photoshop (advanced)
- Figma (design + export)
